AUTOENCODER IMAGE COMPRESSION LAB

How to run:
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html (or right-click it and open with Chrome/Edge).
4. Click Choose an image and select a picture.
5. Move the latent-space dimension slider and compare previews.

Files:
- index.html: webpage structure
- style.css: page design and responsive layout
- script.js: image preview and interactive demo

Important:
This is a front-end educational demo. The reconstructed preview is made by downsampling pixels as a visual approximation; it does NOT train or run a real neural-network autoencoder. The page explains how a real experiment can compare latent dimensions using MSE, PSNR, and compression ratio.
